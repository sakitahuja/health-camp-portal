# CareFlow – Health Camp Portal

CareFlow is a simple and user-friendly Health Camp Portal designed to make basic healthcare information more accessible. It provides a clean interface where users can explore health services, discover upcoming health camps, and learn about available facilities.

The project focuses on a simple design, easy navigation, and a responsive user experience.

🔗 **Live Demo:** https://sakitahuja.github.io/health-camp-portal/

## ✨ Features

- **Clean Homepage:** A simple and welcoming landing page.
- **Health Services:** Displays basic healthcare services.
- **Health Camps:** Highlights featured health camps and related information.
- **Registration Interface:** Provides a basic registration interface for users.
- **Contact Section:** Makes contact information easily accessible.
- **Responsive Design:** Works across desktop and mobile screen sizes.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and layout
- JavaScript – Basic interactivity

## 🚀 Getting Started

1. Download or clone this repository:
   ```
   git clone https://github.com/sakitahuja/health-camp-portal.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code.

## 🎯 Project Objective

The main objective of CareFlow is to create a simple digital platform that presents healthcare services and health camp information in an organized and accessible way.

This project was developed as a beginner-level frontend development project to practice HTML, CSS, and JavaScript.
